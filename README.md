# PRODIGY_DS_02
# Data Cleaning and Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project focuses on performing **Data Cleaning** and **Exploratory Data Analysis (EDA)** on a dataset of choice.

The goal is to understand the dataset, identify patterns and trends, explore relationships between variables, and prepare the data for further analysis.

For this project, the **Titanic dataset** from Kaggle is used.

## 🎯 Objectives

- Clean and preprocess the dataset
- Handle missing values and duplicate records
- Explore the structure and characteristics of the data
- Analyze relationships between different variables
- Identify important patterns and trends
- Visualize the data using charts and graphs
- Generate meaningful insights from the dataset

## 📊 Dataset

The **Titanic dataset** contains information about passengers who were aboard the Titanic.

Some important features include:

- `PassengerId` – Unique passenger identifier
- `Survived` – Survival status
- `Pclass` – Passenger class
- `Name` – Passenger name
- `Sex` – Passenger gender
- `Age` – Passenger age
- `SibSp` – Number of siblings/spouses aboard
- `Parch` – Number of parents/children aboard
- `Fare` – Passenger fare
- `Embarked` – Port of embarkation

## 🧹 Data Cleaning

The following data-cleaning steps were performed:

- Checked for missing values
- Handled missing values where appropriate
- Checked for duplicate records
- Examined data types
- Removed or transformed unnecessary columns
- Prepared the dataset for analysis

## 🔍 Exploratory Data Analysis

The analysis explores questions such as:

- What percentage of passengers survived?
- How does passenger class relate to survival?
- Is there a relationship between gender and survival?
- How does age affect survival?
- How does fare vary across passenger classes?
- What patterns can be observed between different variables?

## 📈 Data Visualization

Various visualizations are used to understand the data, including:

- Bar charts
- Histograms
- Box plots
- Count plots
- Correlation heatmaps
- Scatter plots
